03 · Classification, Routing and Validation

How accurately the pipeline files, and when it defers to a person

Using the text prepared in Capture, I compared two approaches to departmental classification: TF-IDF and sentence embeddings, each paired with logistic regression and calibrated confidence. The models were trained and validated using manually labeled pages. The selected pipeline then used its confidence estimates to determine which pages qualified for automatic filing and which required human review. Its performance was evaluated once on separately labeled test pages, followed by a run on new pages.

Stage 4 of 6: Classification

Sentence embeddings led TF-IDF in cross-validation (macro F1 vs )

The classifiers were developed using manually labeled pages and evaluated through stratified 5-fold cross-validation across six departments. The comparison included a majority-class baseline, a Bates-number probe, TF-IDF with logistic regression, and sentence embeddings with logistic regression.

TF-IDF
Represents documents using word frequencies weighted by how distinctive each term is across the dataset.
Sentence embeddings
represents document text as vectors that capture semantic similarity beyond exact word matches.

Decisions behind this

Why classification is harder without organizational context

In a typical records-management engagement, the filing structure and departmental responsibilities are established with the client, and records retain context such as their originating office, folder, or custodian. LocalRIM instead classifies individual first pages from a litigation archive, without much of that organizational information. The archive's arrangement reflects legal production rather than Philip Morris's original filing practices, making departmental classification more difficult than it would be with those contextual details available.

This approach is particularly relevant to unindexed legacy records, miscellaneous files, and scans whose original filing context is missing. LocalRIM evaluates whether some of these pages can be filed automatically while directing uncertain cases to a reviewer, rather than requiring every document to be examined manually.

Decisions behind this

How the models were tested

  1. Stratified 5-fold cross-validationEach model was trained and evaluated across five fixed folds, stratified by department, with pages from the same archive box kept together (D-56). Each page was evaluated by a model that had not trained on it.
  2. Archive identifiers excludedBates numbers and litigation stamps were removed from classifier input to limit reliance on information unrelated to the document's original purpose.
  3. Macro F1F1 scores were averaged equally across departments, preventing larger classes from dominating the overall result.
  4. Confidence cutoff selected during developmentWithin cross-validation, the automatic-filing cutoff was chosen on the training folds only and applied to the held-out fold. The cutoff used on the final test was frozen beforehand.

How did classification performance change across models?

I compared classification approaches using macro F1 from stratified 5-fold cross-validation on the development pages. The experiments included a Bates-number-only probe, TF-IDF, and sentence embeddings, measured against a majority-class baseline. The selected pipeline was subsequently evaluated on the separate final-test set (Figure 3.11).

Which text should the classifier read?

Four OCR text variants were evaluated using the same TF-IDF classifier and fixed cross-validation folds (D-53). The selection rule, established in advance, specified that the highest-scoring variant would be adopted.

Did better OCR improve classification?

To examine how OCR quality affected classification, I evaluated both classifiers using the baseline Tesseract text and the selected OCR text, keeping the remaining modeling settings unchanged. This comparison addresses research question 3.

Which departments benefited from sentence embeddings?

Departmental classification depends partly on a document's purpose rather than its vocabulary alone. Under labeling rule R9, for example, an agency estimate for an advertising campaign belongs to Finance rather than Marketing because it concerns a financial transaction.

Was classification less accurate on uncertain labels?

During manual labeling, I marked each page as certain or uncertain. I then compared classifier accuracy between these groups to examine whether pages I found difficult to assign were also more likely to be classified incorrectly.

Stage 5 of 6: Routing

Calibrated confidence determines which pages qualify for automatic filing

The routing stage uses calibrated confidence to determine which pages qualify for automatic filing. Pages below the selected cutoff are sent for human review with a ranked suggestion. The cutoff and the target accuracy were established before final testing.

Calibrated confidence
Confidence adjusted on held-out predictions so that, across many pages, a score of 0.9 corresponds to about 90% correct.
Calibrated confidence cutoff, frozen before final testing
< 20tokens: a page with fewer than 20 always goes to human review, regardless of confidence (a frozen setting, D-62)

What information accompanies a page sent for review?

Pages that do not qualify for automatic filing are sent for human review with a suggestion assembled like a records clerk's case file. LocalRIM uses retrieval-augmented generation to retrieve similar labeled records and relevant filing rules. Qwen3 8B, served locally through Ollama, uses that evidence to propose a department, series, and record type, along with a second choice, a brief explanation, and supporting sources. The documents remain on the local computer throughout processing.

RAG (retrieval-augmented generation)
Retrieval-augmented generation (RAG) uses relevant records and filing rules as supporting context for the model's suggestions.

Decisions behind this

How accurate were retrieval-augmented review suggestions?

I evaluated review suggestions on pages routed for human review during cross-validation. Each page was evaluated using a model that had not trained on it. Under the criterion established in advance (D-61), the retrieval-augmented suggestion was considered more accurate only if it identified the correct department more often than the classifier's first choice.

How did the pipeline perform on the final test?

After model selection and routing rules were finalized (D-62), I evaluated the pipeline once on separately labeled test pages that had not been used during development (D-63). Results are presented with 95% confidence intervals to show the uncertainty associated with the limited test sample.

What happens to a box of new pages?

I ran the frozen pipeline on previously unlabeled archive pages (D-64), the situation a client would actually face. Without reference labels, the number of incorrect automatic filings could only be projected from final-test accuracy. In a blind spot-check, I labeled automatically filed pages; my label matched the model's on of the that could be judged.
