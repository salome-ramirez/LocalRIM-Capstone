Project log: decisions and development

I've fed millions of records through a scanner, each batch guided by a barcode someone had to assign by hand. This project asks a simpler question: what if the system could read the page and file it itself, and know when to ask for help?

This log documents the decisions made across LocalRIM's six completed stages. Each entry records what was decided, why, and which part of the project it shaped.
